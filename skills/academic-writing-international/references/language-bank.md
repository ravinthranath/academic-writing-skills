# Academic language bank

Phrase banks for pass 1 (academic conventions). Categories follow the Manchester Academic Phrasebank (University of Manchester). Use phrases as patterns, not as fill-in templates; vary them.

## 1. Formality: informal → academic

| Informal | Academic |
|---|---|
| a lot of, lots of | a large number of, many, considerable (or the figure) |
| get, got | obtain, receive, become |
| big, huge | large, substantial, major (or the figure) |
| thing, stuff | name the specific object, factor or idea |
| look into | investigate, examine |
| find out | determine, establish, identify |
| go up / go down | increase / decrease, rise / fall |
| put up with | tolerate |
| come up with | devise, propose, develop |
| kind of, sort of, pretty | somewhat, relatively (or cut) |
| really, very, totally | cut, or quantify |
| basically, actually, obviously, clearly | cut (or justify with evidence) |
| nowadays, these days | currently, in recent years (better: since [year]) |
| can't, don't, it's, won't | cannot, do not, it is, will not |
| like (as example) | such as, for example |
| OK, fine | acceptable, adequate |
| rhetorical questions | statements of the problem or research question |
| exclamation marks | remove |

## 2. Hedging (cautious language)

Match the strength of the hedge to the strength of the evidence. Do not hedge established facts, definitions, or your own measured results ("accuracy was 91.2%").

**Modal verbs:** may, might, could, would, can.
**Lexical verbs:** suggest, indicate, appear, seem, tend to, imply.
**Adverbs:** possibly, probably, likely, arguably, generally, often, largely, to some extent, in part.
**Adjectives:** possible, probable, likely, apparent.
**Quantity/frequency:** some, many, most, a number of, often, in most cases.

**Distancing patterns**
- It is thought / believed / reported that...
- There is some evidence to suggest that...
- If the findings of Smith (2021) are accurate, ...
- These results appear to indicate that...
- One possible explanation is that...

**Cautious interpretation**
- These data must be interpreted with caution because...
- These findings cannot be extrapolated to all [population] because...
- The possible bias in these responses should be borne in mind.
- This may be partly explained by...

**Before / after**
- "Children living in poverty do poorly in school." → "Children living in poverty tend to perform less well in school."
- "Fine-tuning causes better generalisation." → "Fine-tuning appears to improve generalisation on the held-out set, although the effect was smaller on out-of-domain data."
- "The model is biased." → "The model's error rate was higher for [group] (12.4%) than for [group] (6.1%), which suggests a disparity in performance."

**Over-hedging (fix):** "This could potentially possibly suggest..." → "This suggests..."

## 3. Boosting (use sparingly, only with strong evidence)

clearly demonstrates, consistently, it is well established that, strong evidence indicates, undoubtedly (rare), conclusively (rare). Use a booster only where several high-quality sources or your own robust results support it.

## 4. Reporting verbs

| Neutral | Tentative | Strong / critical |
|---|---|---|
| states, describes, reports, notes, observes, explains, outlines, presents | suggests, proposes, implies, speculates, hypothesises, indicates | argues, asserts, contends, maintains, demonstrates, establishes, refutes, challenges, disputes, questions |

Choose the verb to show your stance on the source: "Smith (2020) **claims** X" signals doubt; "Smith (2020) **demonstrates** X" signals acceptance.

## 5. Being critical

- Smith's (2020) argument relies on the assumption that...
- A major limitation of this study is its small sample (n = 24).
- Although Jones (2021) reports high accuracy, the evaluation used only one dataset.
- These findings conflict with those of Lee (2019), possibly because...
- The study does not address...
- The conclusions are not fully supported by the data because...

## 6. Comparing and synthesising sources (literature review)

- Similarly, / Likewise, / In line with this, ...
- In contrast to X (2019), Y (2022) found...
- Whereas X focuses on A, Y examines B.
- Several studies (A, 2019; B, 2020; C, 2022) have reported...
- There is broad agreement that...; however, there is less consensus on...
- None of these studies has examined... (the gap)

**Source-by-source → synthesis**
- Before: "Smith (2020) used CNNs. Jones (2021) used transformers."
- After: "While convolutional models dominated early work (Smith, 2020), transformer-based approaches have since reported higher accuracy on the same benchmark (Jones, 2021), although neither study evaluated robustness to distribution shift."

## 7. Cohesion and signposting

| Function | Devices |
|---|---|
| Addition | in addition, also, furthermore (sparingly) |
| Contrast | however, in contrast, conversely, whereas, although, nevertheless |
| Cause / effect | therefore, consequently, as a result, because of, owing to, thus |
| Example | for example, for instance, such as, in particular |
| Sequence | first, second, subsequently, finally |
| Concession | although, despite, while it is true that |
| Summary | overall, in summary, taken together |

Signposting at section level: "Section 3 describes the method; Section 4 presents the results." Use once in the introduction, not in every section.

## 8. Describing data, trends and quantities

- The proportion of X rose from 12% in 2019 to 31% in 2024.
- Accuracy fell sharply / slightly / steadily after epoch 20.
- Approximately two thirds of respondents (n = 142, 66.4%) reported...
- There was a strong positive correlation between X and Y (r = 0.78, p < .001).
- Give units, sample sizes, test names and confidence intervals with every statistic.

## 9. Defining terms and acronyms

- In this report, X refers to...
- X can be defined as... (Author, year).
- Write the full term first: "large language model (LLM)", then use LLM consistently. Do this once per document (and again in the abstract, which is read separately).

## 10. Nominalisation

Use moderately. "The model was evaluated" → "Evaluation of the model showed..." Avoid long noun stacks ("model performance evaluation result analysis"). Keep the actor visible where it helps clarity.

## 11. Paraphrase, summary, quotation

- **Paraphrase:** change both wording and structure; keep the meaning; cite.
- **Summary:** condense main points; cite.
- **Quotation:** only when the exact wording matters; short; with page number where the style requires it.
- Using paraphrasing tools ("spinning") to disguise copied text is treated as misconduct at many universities.
- Secondary citation: "(Smith, 2001, cited in Jones, 2020)"; only the source you read goes in the reference list (style-dependent).
